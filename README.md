# Python Quiz Game

A simple quiz game made with Python.
The game asks multiple-choice or text-based questions and keeps track of your score.

## What You Can Use It For

This project can be used not only for fun quizzes, but also as a way to:

* Practice and improve knowledge in different subjects
* Create educational quizzes
* Check your understanding of topics like English, science, history, and more
* Build interactive learning experiences

## How to Run

1. Make sure Python is installed
2. Download the project
3. Run the file:

```bash
python quiz_game.py
```
